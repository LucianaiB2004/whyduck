# 支付宝 SDK 请求依赖安全核查

核查日期：2026-10-08。

最初 npm audit 报告 urllib 4.9.0 的高危跨来源重定向凭据泄露：[官方 GitHub Advisory GHSA-hq3h-g68c-hp78](https://github.com/advisories/GHSA-hq3h-g68c-hp78)。官方明确修复版为 4.9.1。此风险涉及 HTTP 客户端跟随跨来源重定向仍保留认证请求头。

alipay-sdk 4.14.0 的实际依赖声明 urllib:^4，可使用兼容补丁。当前默认 registry 查询仅显示 4.9.0，而指定 https://registry.npmjs.org 查询 urllib@4.9.1 能正常返回。工程由主代理升级并锁定该补丁；实际 npm ls urllib 已核对 SDK 与根依赖去重使用 4.9.1。不要通过关闭验签或移除官方 SDK 来消除扫描项。

生产请求不提供任意支付宝 gateway 覆盖；固定官方 SDK 默认网关。补丁安装和本地协议测试不代表支付宝沙箱/实网验收。后续更新继续运行 npm audit --omit=dev、类型检查及集成测试，遵循最终锁文件。
