# 支付宝凭证获取步骤

核查日期：2026-10-08。支付宝凭证属于项目所有者创建的应用，不是模型服务的 API Key，也不是助手提供的账户。

1. 登录 [支付宝开放平台控制台](https://open.alipay.com/develop/manage)，完成开发者身份要求，创建或选择本项目应用。小程序 APPID 用于小程序工程；网页身份授权需要该应用实际获准的网页授权能力，不假定任意应用都拥有全部权限。
2. 在应用详情保存 APPID，对应 `ALIPAY_APP_ID`。
3. 使用平台主账号进入应用的「开发设置 → 接口加签方式」。本工程目前使用 RSA2 密钥模式。按 [官方设置密钥加签方式说明](https://opendocs.alipay.com/common/02kdnc) 生成应用密钥对，在平台上传应用公钥并取得支付宝公钥。应用私钥留在本地或服务器，不上传聊天或提交源码。
4. 应用私钥填入 `.env` 的 `ALIPAY_PRIVATE_KEY`，支付宝公钥填入 `ALIPAY_PUBLIC_KEY`。不要把应用公钥误填成支付宝公钥。多行 PEM 可以放在双引号内并使用 `\n` 表示换行；适配器读取后还原换行。
5. 配置正式同源 HTTPS 服务地址 `PUBLIC_ORIGIN`，授权回调为 `https://你的域名/api/alipay/callback`，按 [授权回调地址说明](https://opendocs.alipay.com/common/02qjlq) 在平台设置。域名和对应能力必须实际可用，不能使用 127.0.0.1 作为公众正式回调。
6. 完成应用能力申请后设置 `ALIPAY_ENABLED=true`、重启服务，再从网页设置页面发起授权并完成实网验证。仅填入凭证不会让程序声称已关联。

配置项：

| 本地配置 | 获取位置 |
| --- | --- |
| ALIPAY_APP_ID | 应用详情 |
| ALIPAY_PRIVATE_KEY | 自己本地生成的应用私钥 |
| ALIPAY_PUBLIC_KEY | 平台配置应用公钥后提供的支付宝公钥 |
| PUBLIC_ORIGIN | 自己部署应用的 HTTPS 域名 |

以上是应用身份授权配置，未申请订单读取、账单读取或退款权限。比赛相关 AI 平台接入还需要登录 [支付宝 AI 开放平台](https://open.alipay.com/ai/ai-resource-center/welcome)，核查当前可申请通道与比赛要求；普通应用密钥不等于 AI 平台准入。

官方 [接口加签方式说明](https://opendocs.alipay.com/common/02mriz) 已通过浏览器实际读取：适用小程序、网页、移动及第三方应用；平台主账号配置；一个 APPID 只能配置一种密钥或证书方式。
