# 凭啥鸭支付宝小程序

导入此目录为工程根目录。六页面共用 Web API 与账户令牌；HTTPS 域名必须配置为平台白名单。在 Web 设置签发令牌，设置页验证连接，离开设备时清除并从 Web 撤销。

运行 node miniapp/validate.mjs 做工程与语法检查。实际支付宝开发者工具编译与真机验证尚未执行，无法当成上线版本。图片提取字段必须在 Web 原件核对页面确认；小程序仅支持文本材料核对，避免无法查看原件时误确认。

详见 ../docs/integrations/支付宝与MCP集成.md。原始订单不写入分享参数，分享只包含产品入口。聊天采用请求完成后刷新；真机长请求超时需联调评估。
